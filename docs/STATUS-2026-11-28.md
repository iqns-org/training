## 4. Smells (structural, not broken)

- **Suite merge is implicit**: loader globs ALL `bench/*.json` (21+8=29)
  — a peer adding a suite silently changes what "the bench" means and
  which models it probes. Fine for trend ids, surprising at 2am.
- **Truncation fields still shipped**: `row.answer` (120) and table
  (60) remain; the sink is opt-in. The right default for humans is the
  file, not the flag — candidate to always-write-next-to --json.
- **Evidence lives in `tmp/`** (bench-*.md, r3-profile.json, mined
  pairs): gitignored, GC-adjacent, cited-in-docs. If a doc cites a
  number, its artifact should live where the citation survives.
- **Two roots read by bundle** (datasets + tmp) — pragmatic then, but
  it's how homeless-pairs-type bugs happen.
- **seed fixed, repeats vary only temperature path**: bench variance is
  across 3 repeats at temp 0 — effectively deterministic; run-to-run
  ENGINE variance (new pod, new image) is unmeasured. Trend across
  eras carries an invisible confound.
- **kubectl only from pi00** — convention, not enforced; every fresh
  agent rediscovers it.
