## 3. Bugs (found or confirmed this pass)

- **A. `bundle --dpo` silent byte-swap — FIXED + guarded.** The
  default source (tmp/dpo.jsonl) is rewritten by every `derive`; a
  bare bundle would have moved promoted preference bytes silently.
  The guard hashes the WRITTEN output (conversion is deterministic)
  and warns loud on drift. Test-pinned. It fired exactly once, on the
  truth run: r1's 960-pair bytes were unrecoverable — my afternoon
  "backup" had captured an already-regenerated file (three parallel
  derives raced it at ~15:48; the cp won nothing). Canonical
  preference is now the current structural population (`edfa5396`,
  1,231 pairs — same generator law, current scenarios). **Lesson:
  a sha at capture time or it didn't happen.**
- **B. Conversion format drift — FIXED.** r4 churn leaked `_src`/`why`
  keys into preference rows, making even correct input convert to
  new bytes. Canonical 2-key conversion restored; test pins it.
- **C. SIGPIPE truncation — self-inflicted, fixed by practice.**
  Piping `bundle | head -1` killed a write mid-file. Long writes get
  full logs, never head-pipes. Recorded in the anti-pattern register.
- **D. Counterfactual: 0/3 certifiable — PRE-EXISTING, NAMED.**
  Program-shaped golds repeat the same statement text across edits;
  string-cleanliness cannot certify them. Needs answer-SET
  certification, not more rotation. Small population; honest limit.
- **E. Equivalence 54% clean — DIAGNOSED, then RESOLVED the same
  evening (r4.1).** The ceiling I attributed to cross-file vocabulary
  was largely a pool bug: EQ template 6 was the only phrasing without
  {domain.subject.iri}, and files with constant my:Draft/my:Published
  pairs repeated that one sentence every index-5 entry (a 280-row
  collision cluster). Every template now quotes the subject, and the
  converter RE-ROTATES against the current pool (idempotent by
  recompute, not skip) so pool edits can never freeze. verify-measured
  after re-rotation: equivalence 54% -> **84%** gold-clean
  (uniq 0.001 -> 0.187), overall census 90% -> **92%**. The residual
  sub-100% families (diagnosis 82, valid-program 89, repair 98) are
